# PROPOSED UPDATES TO NTCIP 8001 {.annex}

## Reaffirming documents

Currently, NTCIP standards never expire and no guidance is provided as to the current relevance of an old standard. The NTCIP effort should consider a re-affirmation process, similar to that used by ISO and other standards organizations. In order to be re-affirmed, the exact same text of the standard (without any changes) must be re-balloted and approved. Thus, re-affirmed standards have demonstrated a great deal of stability.

## Rescinding documents 

Currently, there are no formal rules for rescinding an NTCIP standard. If an NTCIP standard is no longer needed, it should be rescinded, either by vote or by allowing the its reaffirming period to lapse. A status of rescinded would indicate that there is no longer any version of this standard that is recommended for use.

## Other proposed updates
1. Review and extend duties of chairs, and vice chairs.
